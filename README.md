# Заводы сборных домов Украины

Каталог и сравнение 16 украинских производителей сборных домов под серию домов ~100 м² под ключ.

Одностраничный самодостаточный сайт: сетка карточек, в карточке — фотографии со ссылками на первоисточник,
проверка по требованиям проекта, графики цены и срока производства, расчёт на серию из 74 домов,
таблица параметров и вопросы для обзвона.

Данные собраны с официальных сайтов компаний 02.09.2026. Фотографии принадлежат производителям
и используются для сравнения; под каждой — ссылка на страницу проекта или файл на сайте компании.
